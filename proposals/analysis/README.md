# Analysis

This part gives the calculations that support the proposals. Each sub-tab gives one topic.

- **Beta.** Builds and Tree balance use the proposed trees of calculator version 6 (beta of 30 October 2026). The other tabs use the beta trees of 18 October 2026. Each of these tabs starts with a short part for the beta of 30 October.
- **Withdrawn proposals.** The tabs also examine proposals that were withdrawn on 31 October 2026. Withdrawn ideas gives the reasons.

| Sub-tab | What it gives |
| --- | --- |
| [Crushing blows](crushing-blows.md) | The crushing blow problem, how Redoubt (C-P1) fixes it, and the stat targets of the tank |
| [Threat](threat.md) | Threat of the Paladin, the Warrior and the Druid at each gear tier |
| [PvP burst check](pvp-burst-check.md) | The PvP burst on the beta of 30 October (C1, C-P12), and the earlier check of the Reckoning build (C-P6) |
| [Mana](mana.md) | Mana of Protection and Retribution, in the beta and with the proposals |
| [Healing](healing.md) | The Holy Paladin against the Priest, the Druid and the Shaman |
| [Damage](damage.md) | Retribution damage against the other damage classes |
| [Builds](builds.md) | The main builds for each spec and role, with version 6 codes |
| [Tree balance](tree-balance.md) | The rows and points of each tree against the other classes |
