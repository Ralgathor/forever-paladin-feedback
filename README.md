# Forever Paladin feedback

Unofficial player feedback for the Paladin in **World of Warcraft: Forever**. This project is not affiliated with Blizzard Entertainment.

It contains 17 talent proposals (15 changes and 2 new talents) for Holy, Protection and Retribution, plus a talent calculator that opens in Proposed mode, with a Beta toggle.

## The three biggest changes

- **Protection: crushing blows.** Casting Holy Shield also triggers Redoubt, so block stays high enough to push most crushing blows off the attack table (P4).
- **Protection: Reckoning.** Charges come from Block, Dodge and Parry as well as from being crit. Holy Strike releases up to 2 stored extra attacks (P8).
- **Holy: mana and layout.** Reverence gives 17/33/50% regen while casting and moves to row 2, so Protection and Ret can use it with an 8-point dip. Healing Light moves to row 6 (H1, H6).

## Read and try

- [Proposals (full document)](proposals.md): every change with the beta text, the proposed text, the reason, the model talent from another class, tests and numbers.
- [Talent calculator](calculator/index.html): it opens in **Proposed** mode; use the **Beta** button to compare with the current beta trees. Build codes starting with `p` load a Proposed build, and codes without it load a Beta build. Live version: https://ralgathor.github.io/forever-paladin-feedback/calculator/

Talent icons load from Wowhead's icon server (wow.zamimg.com). If they cannot load, the calculator shows drawn placeholder icons instead. No game assets are stored in this repo.

## How the proposals were made

- Beta client build 1.60.1.70425. Talent text comes from [wowforevertalents.com](https://wowforevertalents.com/), tested behavior from player tests.
- Each proposal follows a talent another class already has in the same beta (Warrior, Druid, Priest, Shaman, Hunter, Mage).
- Combat and mana numbers use Classic 1.12 rules unless a test says otherwise. Burst and threat numbers are estimates, not simulations.
