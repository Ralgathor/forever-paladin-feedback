wowsims sets

Item pool sets (damage)

The final set of each spec in Analysis, Damage, part 7: the same pre-raid item pool, enchants and consumables for each spec. Each link opens the set in wowsims Forever with the raid buffs and the fight (level 63 boss, 2 min). Select Simulate to run it. The values in the analysis come from wowsims master commit 8c7b5a5f5 (13 November 2026), with the ranged judgements of the hotfixes of 11 November. A later wowsims version can give a different DPS.

  • Fury Warrior
  • Combat Rogue
  • Hunter
  • Fire Mage
  • Demonology Warlock
  • Retribution

Item pool tank sets (threat)

The sets of Analysis, Threat, parts 5 to 9, and Protection. Each tank set obeys the item pool rules of Analysis, Damage, part 7: no raid drops, no Zul'Gurub or Ahn'Qiraj items (item ids 19000 to 23999), no PvP items, no Revered or Exalted reputation items, item level 63 or lower. Each class has its default enchants, talents and rotation, full buffs, one level 63 boss in front of the tank, 3 min. The Paladin has tank consumables (the consumables of the Warrior test, with Greater Arcane Elixir and Brilliant Wizard Oil). The values come from wowsims master commit 8c7b5a5f5 (13 November 2026, hotfixes of 13 November), with the ranged judgements of the hotfixes of 11 November. The Warrior and the Druid have the threat multipliers of the notes of 2 November. Since commit 52471a100, wowsims also gives Lacerate 10/3 threat for each point of damage (Druid +43%).

  • Protection Paladin (live: 1,139 threat per sec)
  • Protection Warrior (1,525 threat per sec)
  • Bear Druid (2,277 threat per sec)

Item pool tank sets (survival)

The same item pool rules, with a search score that favors survival: 40% threat, 30% damage taken and 30% TMI (threat sets: 40% threat, 20% damage, 20% damage taken, 20% TMI). Analysis, Threat, part 6, Crushing blows, part 3, and Protection give the values of the two sets.

  • Protection Paladin (live: 1,090 threat per sec)
  • Protection Warrior (1,386 threat per sec)
  • Bear Druid (2,163 threat per sec)

Default tank sets

The default tank set of each class in wowsims Forever. These sets have raid, PvP and reputation items. The earlier versions of the threat analysis used these three sets.

  • Protection Paladin (live: 1,038 threat per sec)
  • Protection Warrior (1,470 threat per sec)
  • Bear Druid (2,503 threat per sec)

Builds sets

The sets of the Builds tab, from the same item pool: the Retribution item pool set (RB1, the Retribution set of the damage comparison) and the Shockadin set (SB1, the wowsims Holy Shock set with the items that are not in the pool replaced). Full buffs, one level 63 boss, 3 min. The Protection builds use the item pool Protection Paladin set above. Holy has no wowsims healing sim, thus no link.

  • Retribution (830 DPS)
  • Shockadin (816 DPS)
