wowsims sets

Item pool sets (damage)

The final set of each spec in Analysis, Damage, part 7: the same pre-raid item pool, enchants and consumables for each spec. Each link opens the set in wowsims Forever with the raid buffs and the fight (level 63 boss, 2 min). Select Simulate to run it. The values in the analysis come from wowsims master commit 8298ab833 (4 November 2026). A later wowsims version can give a different DPS.

  • Fury Warrior
  • Combat Rogue
  • Hunter
  • Fire Mage
  • Demonology Warlock
  • Retribution

Item pool tank sets (threat)

The sets of Analysis, Threat, parts 5 to 9, and Protection. Each tank set obeys the item pool rules of Analysis, Damage, part 7: no raid drops, no Zul'Gurub or Ahn'Qiraj items (item ids 19000 to 23999), no PvP items, no Revered or Exalted reputation items, item level 63 or lower. Each class has its default enchants, talents and rotation, full buffs, one level 63 boss in front of the tank, 3 min. wowsims gives the Warrior and the Druid threat without the multipliers of the notes of 2 November. The analysis multiplies the Warrior threat by 1.445 and the Druid threat by 1.433.

  • Protection Paladin (live: 1,029 threat per sec)
  • Protection Warrior (1,002 threat per sec, 1,448 with the multiplier)
  • Bear Druid (779 threat per sec, 1,116 with the multiplier)

Item pool tank sets (survival)

The same item pool rules, with a search score that favors survival: 40% threat, 30% damage taken and 30% TMI (threat sets: 40% threat, 20% damage, 20% damage taken, 20% TMI). Analysis, Threat, part 6, Crushing blows, part 3, and Protection give the values of the two sets.

  • Protection Paladin (live: 976 threat per sec)
  • Protection Warrior (957 threat per sec, 1,383 with the multiplier)
  • Bear Druid (764 threat per sec, 1,095 with the multiplier)

Default tank sets

The default tank set of each class in wowsims Forever. These sets have raid, PvP and reputation items. The earlier versions of the threat analysis used these three sets.

  • Protection Paladin (live: 980 threat per sec)
  • Protection Warrior (965 threat per sec, 1,394 with the multiplier)
  • Bear Druid (847 threat per sec, 1,213 with the multiplier)

Builds sets

The sets of the Builds tab, from the same item pool: the Retribution item pool set (RB1, the Retribution set of the damage comparison) and the Shockadin set (SB1, the wowsims Holy Shock set with the items that are not in the pool replaced). Full buffs, one level 63 boss, 3 min. The Protection builds use the item pool Protection Paladin set above. Holy has no wowsims healing sim, thus no link.

  • Retribution (915 DPS)
  • Shockadin (840 DPS)

Source: models/wowsims-b2/matched_gear (item pool sets), models/wowsims-b2/tank_gear (item pool tank sets) and models/wowsims-b2/sets (tank and builds sets).
